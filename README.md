## 📝 Notes on my approach

I don't use every tool on this list. Some are part of my daily workflow. Others I've tested once or twice to understand what they can do. And some I've only researched because they're relevant to the L&D landscape I work in.

What matters more than the tool itself is knowing how to evaluate it: does it actually solve a problem, or does it just look impressive? Does it fit into an existing workflow, or does it create a new one? Can I verify the output quality, or does it require blind trust?

I'll add notes for each tool as I go: what I tried, what I learned, and whether I'd recommend it.
